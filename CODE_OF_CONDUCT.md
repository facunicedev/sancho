# Code of conduct

## The short version

Be decent. Assume the other person is trying.

## What that means here

Discussion in this repository is about the method: whether a rule holds up, whether a hook reports the right thing, whether the workflow survives a job that is not the one it was built for. Disagree with the idea as hard as you like.

Not welcome: personal attacks, harassment, insults about someone's job, their level of technical skill or their language. Most people reading this repository do not program, and treating that as a deficiency misses the entire point of it.

English and Spanish are both fine in issues. So is imperfect either.

## If something goes wrong

Open an issue, or contact the maintainer through GitHub if it should not be public. Reports are read and handled privately.

Consequences scale with the behaviour: a note, a warning, a temporary block, a permanent one. The maintainer decides, and says why.

## Scope

This applies in issues, pull requests, discussions and anywhere someone is representing the project.
