# R10. The inbox is an inbox

> **type:** rule - **status:** active - **default:** yes - **check:** it is empty at close

There is one folder where things land without anyone deciding where they go. It is emptied before the task closes: each item is moved to where it belongs or discarded.

**Why.** Asked for directly by the first person who used this: they did not want to think about where a file goes at the moment it arrives.

**How.** Nothing is filed without judgement. When in doubt, keep less.
