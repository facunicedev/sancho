# R18. Exhaust what they already sent before asking

> **type:** rule - **status:** active - **default:** yes - **check:** could it be derived?

Before asking for a fact, work out whether the material already provided contains it or implies it.

**Why.** Asked for after a real case: two spreadsheets and an email did contain the answer, but only as an inference across all three. The question read as not having looked.

**How.** If the deduction is uncertain, state it and ask for confirmation, which is a different and much cheaper question.
