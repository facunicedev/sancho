# R08. Four memory files, four questions

> **type:** rule - **status:** active - **default:** yes - **check:** no statement appears in two of them

`HANDOFF.md` says where the session stopped. `Documents/TASKS.md` says what was done in each task. `MEMORY.md` says how to work with this person. `Knowledge/PROFILE.md` says who they are.

**Why.** When two files answer the same question they drift apart, and then neither can be trusted. Measured on a real repository: sixteen rules written ninety times across twenty files.

**How.** Before writing a line, ask which of the four questions it answers. If it answers none, it does not belong in memory.
