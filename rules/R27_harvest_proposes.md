# R27. What is learned is proposed, not written into memory

> **type:** rule - **status:** active - **default:** yes - **check:** the proposal file exists

When a task produces something reusable, it goes to `Proposals/` with its type, its origin and its status. The person approves or discards. Only then does it become a rule card.

**Why.** Three independent measurements agree: context written by a person raises accuracy; context a model writes for itself lowers it. Skills curated by people help; skills a model writes for itself average out to nothing.

**How.** If there is nothing to propose, propose nothing. An empty proposal costs the same as a full one.
