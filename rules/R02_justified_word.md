# R02. Body text in Word is justified

> **type:** rule - **status:** active - **default:** yes - **check:** open the file and look

Every Word document ships with justified body text and margins set in inches, never in points.

**Why.** It is what an office document looks like. And margins set in points instead of inches produce roughly zero margin, which puts the text against the edge of the page. That happened once, on a document already sent.

**How.** The template already does it. If you generate a document without the template, set both explicitly.
