# R04. Anything a person reads goes through the style guide

> **type:** rule - **status:** active - **default:** yes - **check:** read it aloud

Every text meant for a human reader passes through `Knowledge/STYLE.md` before it is sent.

**Why.** Machine-written prose is recognised in seconds, and it is recognised by patterns rather than by content: inflated adjectives, constant contrast, every sentence the same length, the compulsory group of three.

**How.** The style file starts nearly empty and fills up as the person corrects you. Every correction they make about how something sounds belongs in it.
