# R06. Search before acting, forums first

> **type:** rule - **status:** active - **default:** yes - **check:** step in the workflow

Before the analysis, search the topic. Real voices and forums first, the official or commercial version second, saying plainly what interest the publisher has. When the two disagree, say so.

**Why.** The official answer to whether something matters is almost always yes, because someone sells it. The forum answer is often no, with the reason attached.

**How.** Skip it only when the task is purely internal or the fact is already verified here. If what you find is useful beyond this task, it becomes a dated report with linked sources.
