They have just **signed the checklist** of the current task. The `the_gate.py` hook froze it on its own when the message arrived: there is nothing to write here.

What is yours to do now:

1. Run the checklist in `HANDOFF.md`, item by item, **ticking each one as it finishes** and before starting the next (`WORKFLOW.md`, step 7).
2. If the message carried anything after `/sign`, it is a nuance about the task: fold it in before starting.

**The signature is good for this checklist and this session.** If the list changes, the signature expires by itself and they have to be asked to type `/sign` again. It is not walked around by writing somewhere else.

**And when you ask again, the items and the decisions go in the message** ([R40](../../rules/R40_summarise_what_you_ask_them_to_sign.md)). Pointing them at the file is asking them to sign blind.
